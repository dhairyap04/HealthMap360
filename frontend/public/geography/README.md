# Reporting boundaries

Public-domain Natural Earth vector data, downloaded 2026-11-07 from
https://github.com/nvkelso/natural-earth-vector/tree/master/geojson

- countries.geojson: ne_110m_admin_0_countries.geojson
- regions.geojson: ne_50m_admin_1_states_provinces.geojson

Only identifying properties were retained; geometries are unchanged.
License: https://www.naturalearthdata.com/about/terms-of-use/

These are generalized display boundaries, not authoritative jurisdiction or
public-health catchment boundaries. Regional coverage is limited to the
first-order areas included in Natural Earth's 50m dataset. Missing boundaries
are explicitly shown as unavailable; no centroid bubble substitutes for them.
